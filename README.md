# Leonardo Senerine da Silva

**Full Stack Developer** · React · TypeScript · Node.js · UI Design
Guarulhos, SP — Brazil

I design and build web applications end to end, from the first screen in Figma to the API and the deploy. I currently work at **Focus Automação de Sistemas (iFocus)**, building software for industrial environments, where interfaces need to be clear, fast, and reliable on the factory floor.

---

## 💼 What I've been working on

- **Smartcip** — Digital CIP (Clean-in-Place) cleaning record system for a Beiersdorf plant. I designed and built the screens and took part in factory floor testing with production teams. It replaced the paper-based records.
- **Multi-tenant ERP** — ERP with a Jira/Monday-style project management module. I designed and built the frontend and worked on the NestJS backend, which follows Domain-Driven Design.
- **Industrial monitoring platform (Cimed)** — Figma prototypes for compressed air, steam, and water treatment modules, with a semantic color system and a modular component library.
